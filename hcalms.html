Consistency over intensity. Follow this daily structure to maintain high velocity and momentum.

00:00 - 00:15
(15 mins)

1. Daily Warmup & Quest Review

Open HCA LMS, review today's quest item, clear workspace distractions, and inspect Git repository status.

00:15 - 01:15
(60 mins)

2. Deep Learning Block (Core Module Study)

Work through freeCodeCamp, Odin Project, or Full Stack Open assigned modules without multi-tasking.

  • Read concept documentation & write hands-on syntax snippets.
  • Complete interactive practice exercises & algorithm katas.
01:15 - 02:00
(45 mins)

3. Practical Coding Sprint & Implementation

Apply new concepts directly into real code projects or technical challenge briefs.

Weekly Structure & Execution Cadence (16–18 hrs/week)

The alternating Odd/Even week strategy guarantees theoretical understanding + tangible public project output.

Monday – Wednesday
~7.5 Hours

Phase 1: Foundations & Theory

Absorb core architecture concepts, interactive course lessons, and syntax experiments.

  • Complete primary module readings (freeCodeCamp / Odin / Full Stack Open).
  • Take structured notes and solve micro-challenges.
Thursday – Friday
~5 Hours

Phase 2: Project / Assignment Sprint

Focus on real-world practical application depending on week type:

  • Odd Weeks (Challenge Focus): Solve targeted technical katas & layout/logic puzzles.
  • Even Weeks (Assignment Focus): Build real-world Humanitarian assignment briefs (e.g., Disaster Info UI, Food Bank API).
Saturday
~3 Hours

Phase 3: Code Polish, Testing & Deployment

Refactor code for clean architecture, test responsiveness, and deploy live previews.

  • Push commits to GitHub and deploy to Vercel/Render/GitHub Pages.
  • Verify Web Accessibility (WCAG) and browser compatibility.
Sunday
~2 Hours

Phase 4: Public Output, LMS Update & Rest

Finalize content shipping and plan the upcoming week.

  • Publish Devlog Video (Odd Wk) or Blog Guidebook Chapter (Even Wk).
  • Mark finished quest checkboxes on LMS to update your roadmap progress.
  • Log account book earnings if applicable. Rest and reset!
